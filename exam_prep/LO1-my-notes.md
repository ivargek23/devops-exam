# 1: Introduction and overview of containers

Container image => contains immutable data that defines an application and its libraries
Container instance => a running instance of a container image

Container vs VM

Machine-level functionality:
Container engine    Hypervisor

Management:
Container engine or orchestration software    VM management interface

Virtualization level:
Only relevant parts     Fully virtualized environment

Size:
Megabytes    Gigabytes

Portability:
Any OCI-compliant engine    Limited to specific hypervisor
